# rezIA 🙏

A **rezIA** é uma aplicação feita em Python pensada para os católicos do Brasil — o país com o maior número de devotos no mundo. Quem nunca sentiu falta de alguém para rezar junto?

Com a rezIA, você nunca mais vai rezar sozinho.

---

## ✨ O que é?

É um programa simples, mas poderoso: você escolhe uma oração a partir de um menu, e a rezIA reza *em voz alta* com você. Isso mesmo — ela fala junto, como uma verdadeira companhia de fé.

---

## 🎯 Por que isso importa?

Todo católico já teve aquele momento de solidão ou dificuldade para se concentrar na oração. A rezIA usa a tecnologia para resolver esse problema do dia a dia, ajudando a manter sua prática de fé firme, com alguém ali, mesmo que digital, para rezar com você.

---

## 🚀 Como usar

1. Clone o repositório ou baixe o código.
2. Instale as dependências. (pip install pyttsx3)
3. Execute o script Python.
4. Escolha a oração no menu e reze junto!

---

## 📦 Requisitos

- Python 3.11  
- Biblioteca de síntese de voz (`pyttsx3`)
